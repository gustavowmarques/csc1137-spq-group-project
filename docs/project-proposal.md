# Project Proposal

**Project:** MediTrack – Patient Management System

---

## Overview

MediTrack is a web-based patient management system built for healthcare professionals. The primary goal is to demonstrate the application of SQA principles across the full development lifecycle rather than building a production scale application.

---

## Target Users

- **Doctor:** records patient visits and prescriptions, reviews full medical history
- **Nurse:** views patient information within permitted access levels
- **Admin:** manages user accounts and assigned roles

---

## Functional Scope

- Create and manage patient records
- Record patient visits and clinical notes
- Manage prescriptions including dosage and dates
- Track patient allergies and severity
- Enforce role-based access so each user only sees what they should

---

## Agile Process

The team will work in short iterative cycles with the following practices:
- Prioritised backlog with user stories and acceptance criteria
- GitLab issue board used for all task tracking
- Regular group reviews of progress and process

---

## Expected Outcomes of Phase 1

- Defined project scope and domain
- Initial Agile backlog and workflow
- Agreed DoR and DoD
- Working CI pipeline and project board
- Documented evidence of planning and team collaboration
